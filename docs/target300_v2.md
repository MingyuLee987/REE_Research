# 300개 목표 추가 수집 및 결측률 80% 기준

2026-10-16 작업 결과: **36편·233개 실험 보고값**을 저장했다. 이번에 3편에서 8개를 추가했으며 **300개 목표까지 67개가 부족하다.** 임시 분석 후보는 151개, 보류는 82개다. 정규화된 i_corr가 있는 자료는 218개이며 기존 AH36 15개는 원문 배율 미확정으로 타깃을 비워 두었다. 사람의 검증 완료 자료는 아직 없다.

원문 블록을 gpt-6.1-sol로 추출하고 근거 문구를 자동 매칭했다. Q355NHq 및 산업 생산 75Cr1강의 타깃 표는 PDF 이미지로도 대조했다. 후자의 문자 인코딩은 손상돼 있어 시각 대조를 병행했다. Q355NHq의 Base 시료도 Ce+La가 30 ppm 보고돼 있으므로 0 ppm으로 바꾸지 않았다. 산업 생산 La-Ce 연구와 이전 실험실 Ce-only 75Cr1 연구는 별개 출판물이지만 관련 재료 계열로 묶어 검증하고 실험 재사용 여부를 추가 확인해야 한다.

비정질 봉재 논문의 명목 Fe-15Mn-5Si-14Cr-0.2C-1Ce 조성은 `nominal_composition_wtpct`에 보관하고 측정된 최종 조성 열에는 넣지 않았다. 원래 연구 범위인 벌크 철계 재료에 해당하나 기존 결정질 강과 다른 재료군이므로 보류한 채 별도 검토한다. 모든 추가 자료는 pending 상태다.

## 검색 및 확보 제한

이번에는 Scopus API와 Springer Nature Metadata/OA API 검색을 새로 실행했다. 저장된 API 응답과 검색식은 `data/raw/target300_v2/`에 있다. 검색 결과는 후보 서지 기록이며 실험 데이터 개수와 다르다. 공식 출판사·학회 페이지에서 후보를 후속 탐색하고 접근 가능한 PDF를 확보했다.

추가 확보한 5Cr강 CO2 논문과 Y 첨가 오스테나이트강 논문에서는 수집 규약에 맞는 명시적 i_corr를 추출하지 못했다. 부동태 전류, 포화 전류, 중량감소 속도, 임피던스를 i_corr로 바꾸지 않았다. 여러 Elsevier 전문 요청은 403, 일부 공식 PDF는 네트워크·접근 오류가 발생했다. 메타데이터·초록만 확보된 후보나 접근이 제한된 원문을 읽은 것으로 간주하지 않았다. 기존 관측값·평균값을 복제하거나 합성값을 추가하지 않았다.

## ML용 컬럼

`ml80` 프로파일은 조성·환경·열처리·시험 전 상 및 상×조성 지표에 시험 전처리·참조전극·측정 방법 등을 포함한 **58개 후보 피처**다. 기존 75개 지원 스키마 중 중복된 원문 범주·변환 전 원시 변수 일부를 제외한 구성이다. 원문에 없는 추가 피처 값을 생성하지 않았다.

현재 임시 후보 **151개 기준**, 결측률 **80% 이하**, 2편 이상에서 보고, 비상수 조건을 만족하는 **36개 피처(수치형 27개·범주형 9개)**를 보기 쉬운 ML CSV로 저장했다. 이 기준은 모델 입력의 피처별 기준이며 전체 감사용 CSV의 모든 메타데이터·희소 원시 열을 삭제했다는 뜻이 아니다. 관측값별 결측률도 별도 저장했으며 모든 셀이 채워진 데이터셋은 아니다.

상분율·Nb/Ti/V/W/Sb·결정립 크기·용존산소·표면 연마도 등 희소 후보는 현재 확보율 또는 논문 수 기준을 통과하지 못했다. 원문 검토용 통합본에는 계속 보관한다. 카테고리는 인코딩 전 피처 개수이며 인코딩 이후 열 수는 다르다.

피처 확보율에 근거한 전체 집계는 설명용이다. 검증 시에는 `CoverageTransformer`가 **학습 폴드에서만** 확보율·논문 수·변동성을 확인하고 결측 대치 및 인코딩을 적합한다. 새 프로파일의 성능이 개선됐다고 주장하지 않으며 이전 R²는 이번 데이터의 평가 결과가 아니다.
