# 수집한 논문 원문과 근거

논문 PDF·XML·HTML, 표와 그림, API 응답을 보관합니다. 하위 폴더는 수집처나 수집 단계 이름입니다. 분석 결과가 아니라 데이터가 어디에서 나왔는지 대조하는 자료입니다.

`europepmc`, `springer*`, `wiley*`, `elsevier*`는 수집처, `additional`, `add30*`, `expand*`, `round300`, `target*`는 수집 작업 묶음입니다. 예전 폴더명의 100·300·400 등 숫자가 실제 확보 논문 수나 측정값 수를 뜻하지는 않습니다.

원문 위치가 추출 표에 기록돼 있어 이 폴더는 이름과 경로를 유지했습니다. 중국어 논문도 수집 이력으로 보관하지만 현재 분석에서는 제외됩니다.
