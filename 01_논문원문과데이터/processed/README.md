# 원문을 표로 정리한 수집·가공 이력

단위 변환, 논문별 검토, 초기 모델 입력 등 단계별 사본을 보관합니다. `pilot100` 등 기존 폴더명 숫자는 현재 자료 수가 아닙니다.

- `pilot100/llm_pending_all.csv`: 중국어 논문을 포함하는 수집 원본 44편·283개 기록.
- `pilot100/current_analysis_dataset.json`: 현재 제외본 경로 안내.
- `paper_review/`: 논문별 원문 대조·검토 자료.
- 나머지 단계별 폴더: 이전 수집·가공 사본.

현재 사용할 표는 [중국어 논문 제외본](../../03_분석결과와실험계획/01_현재분석_중국어논문제외/README.md)을 확인하세요. 원본을 현재 분석본으로 착각하지 않도록 구분했습니다.
