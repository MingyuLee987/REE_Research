# R² > 0.5 목표 추가 탐색 — 미달

2026-10-19. 중국어 논문 제외 조건과 실제 측정 정답을 유지했다. 현재 자료에서 검증 R² > 0.5를 달성하지 못했다. 좋은 분할이나 일부 시료만 선택해 달성한 것으로 표현하지 않는다.

## 주 평가: 다른 논문 계열로 넘어갈 때

학습은 기존 영문 개발 자료 15편·112개다. 관련 La 연구를 묶으면 14개 연구 계열이다. 조성·환경·제조 방법 입력, 비선형 조성 곱, 스플라인, Ridge/SVR/Kernel Ridge/CatBoost/Extra Trees/Random Forest/앙상블, 무가중·계열 균등 가중을 포함한 **202개 설정**을 비교했다.

이전 모델도 기준선으로 포함했다. 사용자 목표에 맞춰 이번 선택 지표는 전체 OOF RMSE 최소화, 즉 같은 정답 집합의 전체 OOF R² 최대화로 정했다. 이는 이전의 계열별 평균 RMSE 선택과 구분된다. 입력 선택·결측 대치·표준화·스플라인 적합·가중은 각 학습 fold에서만 수행했다.

과도한 외삽을 줄이기 위해 각 학습 fold의 로그 정답 최솟값·최댓값으로 예측을 제한했다. 검증·테스트의 정답 범위는 사용하지 않았다. 이 제한은 보수적인 경험적 장치이며 물리적 부식 범위나 외삽 정확성을 보장하지 않는다.

선택은 **전체 조성 Ridge(alpha=100), 계열 균등 가중, 학습 범위 제한**이었다.

| 검증 범위 | log10(i_corr) R² |
| --- | ---: |
| 선택에 사용한 4-fold 개발 OOF | **0.342** |
| 선택 과정 전체를 다시 실행한 3×3 중첩 계열 CV | **−0.286** |
| 과거 영문 테스트 2편·7개 재평가 | **−4.498** |

기존 중국어 테스트 3편이 제외되어 현재 고정 테스트는 없었다. 이번 추가 평가는 이전부터 학습에서 제외한 영문 과거 테스트 `10.3390/met15010085`, `10.1155/2018/4071352`를 기존 경계 그대로 재사용했다. 새로운 유리한 테스트 논문을 고른 것이 아니며, 이 7개는 학습·모델 선택에 넣지 않았다. 다만 이미 과거에 관찰한 자료이므로 **새 독립 외부 검증은 아니다**. 이 테스트를 본 뒤 모델 설정을 조정하거나 더 좋은 테스트 점수만 고르지 않았다.

원래 A/cm² 단위로 역변환한 과거 테스트 R²는 −0.800이다. 로그 목표의 점수와 원래 단위의 점수를 혼동하지 않는다. 현재 모델의 외부 적용 성능은 좋다고 판단할 수 없다.

## 보조 평가: 같은 문헌 실험계열 안의 새로운 조성

AL의 조성 선택 목적을 살펴보기 위해 별도 보조 평가를 했다. 112개를 **보고된 조성 서명 38개**로 묶고, 같은 조성 서명의 모든 조건 기록은 같은 fold에 배정했다. 결측 성분은 0으로 채우지 않았다. 보고된 조성이 같다는 것이 실제 완전한 조성의 동일성을 입증하는 것은 아니다.

같은 논문이 학습·검증 양쪽에 등장할 수 있다. 이는 **알려진 문헌 실험계열에서 새로운 조성을 예측하는 범위**이며, 새 논문·새 제조 공정·사용자 합금의 테스트 성능이 아니다. DOI 자체를 피처로 쓰지는 않았지만 환경·공정 정보는 기존 실험계열에서 공유될 수 있다.

| 보조 탐색 | 설정 수 | 선택용 개발 OOF R² | 중첩 조성 CV R² |
| --- | ---: | ---: | ---: |
| 최초 조성 그룹 평가 | 8 | 0.452 | **0.473** |
| 실제 RE wt.%·함량²·함량×시간·함량×온도 등 확장 | 26 | 0.478 | **0.342** |

최초 결과를 확인하고 추가 변수를 설계한 탐색이므로 이 반복 개발 점수도 새로운 독립 검증으로 볼 수 없다. 확대 탐색은 **제조·환경·함량-노출시간 변수의 Ridge(alpha=10)**를 선택했으나 중첩 성능은 낮아졌다. 가장 좋은 0.473만 최종 모델 성능으로 채택하거나 0.5로 반올림하지 않는다.

## 해석과 현재 결정

추가로 202개 주 설정과 26개 보조 설정을 검증했지만, 검증 기준에서 >0.5를 달성하지 못했다. 단순히 모델 복잡도를 높이거나 입력을 늘리는 것으로 해결되지 않았다. 60개 기록이 한 논문에, 70개가 관련 La 연구 계열에 집중되어 있어 독립 정보량은 레코드 수보다 작다. 새 계열을 가릴 때 합금·용액·시간 범위가 크게 바뀐다.

현재 자료·기존 기준 모델은 보존하고 이번 결과를 추가 탐색 이력으로 둔다. 이 결과를 Ce 300 ppm의 성공 예측이나 사용자 실험의 R²로 대체하지 않는다. R²가 임계값을 넘도록 정답을 만들거나, 오차가 큰 논문을 추가 제거하거나, 테스트를 반복 분할하지 않았다.

실험 전 문헌만 더 활용하려면 먼저 다음 입력을 보완해야 한다.

1. Ce 단독·저 Cr 기지 등 사용자 합금과 가까운 영문 연구의 실제 성분과 준비 조건을 확보한다. 현재 개발 자료에는 Cr<5%의 Ce 단독 사례가 없다.
2. 같은 기지·같은 부식 용액에서 Ce 함량 또는 열처리만 바꾼 수치 쌍을 우선 수집한다.
3. 현재 제외된 보류 기록은 단위·조성·측정법의 보류 사유를 원문에서 해결한 경우에만 추가한다. 높은 R²를 위해 적격 기준을 낮추지 않는다.
4. 결과를 보기 전에 별도 영문 논문 또는 실험 배치로 최종 테스트를 지정한다. 이미 본 과거 테스트의 높은 점수만으로 임계값 달성을 주장하지 않는다.
