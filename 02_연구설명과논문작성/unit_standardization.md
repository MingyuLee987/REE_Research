# 데이터 단위 통일

`04_분석실행코드/normalize_dataset_units.py`는 기존 통합본과 추가 수집분을 record_id로 대조해 원본 수치를 보존하면서 단위를 정리한다. 현재 수정된 기존 기록이 있으면 그 값을 우선하고 추가 수집본에서는 새로운 ID만 가져온다.

## 부식전류밀도

- `icorr_A_cm2`와 `icorr_value`: A/cm² 기준의 동일한 수치.
- `icorr_unit`: 환산 가능한 기록은 `A/cm2`로 통일.
- `original_icorr_value`, `original_icorr_unit`: 원래 보고 수치·단위·표의 배율을 보존. 예전 기록에서 비어 있던 원본 열은 기존 `icorr_value`·`icorr_unit`에서 옮긴다.
- `unit_conversion_factor_to_A_cm2`: 원래 수치에 곱하는 환산 배율.
- `unit_check_status`: 원본 수치·단위와 기존 정규화 타깃의 일치 여부. 사람 검증 완료를 의미하지 않는다.

1 mA/cm² = 10⁻³ A/cm², 1 μA/cm² = 10⁻⁶ A/cm²다. `1e-7 A/cm2` 등 표에 명시된 배율도 반영한다. 기존 타깃과 환산값이 다르면 덮어쓰지 않고 실행을 중단한다. 이번 225개 중 210개의 명확한 단위는 기존 정규화 타깃과 일치했으며 타깃 수치는 바꾸지 않았다. AH36 15개의 원문 배율 불확실성은 단순 차원 환산으로 해결할 수 없어 원본 숫자만 유지하고 타깃·표준 단위·환산 배율은 비워 둔다.

## 조성 및 시험 조건

| 항목 | 기준 단위 |
| --- | --- |
| 원소 조성 | wt.% |
| 희토류 총함량 | 질량 ppm (1 wt.% = 10,000 ppm) |
| 시험·열처리 온도 | °C |
| 노출·열처리 시간 | h |
| OCP 안정화 시간 | min |
| 분극 스캔 속도 | mV/s |
| NaCl 농도 | wt.% NaCl |
| 염화물 몰농도 | mol/L Cl⁻ |
| 결정립 크기 | μm |
| 보고된 상·조직 분율 | %; 원문 면적·체적 기준은 유지 |

이 피처 열들은 이미 열 이름과 추출 규약에 따라 위 단위로 저장되어 있다. 이번 작업에서 원문을 다시 읽어 모든 조건 단위를 재검증했다고 주장하지 않는다. 질량분율·원자분율은 원소 전체 조성이 없으면 상호 변환하지 않으며, NaCl wt.%와 Cl⁻ mol/L 역시 밀도·용액 조성 근거 없이 서로 대체하지 않는다. 미보고값을 0이나 실온 25°C로 채우지 않는다. 열별 단위 사전은 `01_논문원문과데이터/processed/units_v1/column_units.json`에 저장된다.

정리본은 `01_논문원문과데이터/processed/units_v1/llm_pending_all.csv`이며 원래 통합본이 잠겨 있으면 별도 정리본만 저장된다. 실제 기존 경로 반영 여부는 같은 폴더의 `status.json`을 확인한다. 수동 검토용 논문별 CSV는 작업 중인 값을 보호하기 위해 자동으로 덮어쓰지 않는다. 기존 모델 점수는 재계산하지 않았다.
