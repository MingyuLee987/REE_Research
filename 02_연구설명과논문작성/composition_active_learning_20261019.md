# 조성 중심 예측과 Active Learning — 2026-10-19

사용자가 요청한 목적에 맞춰 **조성 → i_corr 예측**과 **다음에 확보할 조성을 고르는 Active Learning(AL)**을 실제로 실행했다. 현재 문헌 데이터에서 정답을 가렸다가 선택 시 공개하는 후향적 시뮬레이션이다. 새 합금을 제조하거나 새로운 실험 정답을 생성한 것은 아니다.

일부 조성 예산에서 AL은 무작위 선택보다 나은 결과를 보였다. 그러나 개선은 단조롭지 않았고, 모든 조성을 사용하면 선택 순서의 이점은 사라졌다. **R²≥0.8은 달성하지 못했다.**

## 조성의 정의와 데이터

기존 임시 후보에서 과거 테스트 2편·7개를 제외하고, 개발·질의 풀은 19편·135개, 기존 고정 테스트는 3편·9개로 유지했다. 보류·단위 미확정·그림 추정치는 포함하지 않았다. 모든 사용 자료는 독립적인 사람 검증 전이다.

135개 기록을 C, Si, Mn, P, S, Cr, Ni, Mo, Cu, Al, N, Nb, Ti, V, W, Sb, RE 함량 및 RE 종류의 보고값으로 묶으면 **52개 조성 서명**이 된다. 결측은 미보고 토큰으로 유지하며 0으로 치환하지 않았다. 따라서 ‘보고된 조성 서명이 같다’는 것이 실제 조성 전체의 동일성을 입증하지는 않는다. 모델 입력에는 DOI나 시료 ID를 넣지 않았다.

52개 중 13개 조성 서명에는 여러 기록이 있다. 한 조성 서명의 전류 값 범위는 최대 약 8,483배 차이가 났다. 시험 조건·공정·미보고 성분·출처 오류 등의 영향을 따로 점검해야 하며, 이를 단순히 측정 잡음이나 희토류 효과라고 단정하지 않는다. 이 관찰은 조성만으로 혼합 문헌 전체의 i_corr를 유일하게 결정하기 어렵다는 점을 보여준다.

## 비교한 모델

두 입력 구성을 비교했다.

- **조성만:** 원소 질량분율, RE 로그함량, RE 종류.
- **조성+조건:** 위 조성에 온도, pH, 염화물·NaCl 농도, 노출시간, 주사속도, OCP 안정화시간, 열처리온도·시간, 전해질·기지·열처리·기준전극·측정법 그룹을 추가.

각 구성에서 Ridge, SVR, GPR, Random Forest, Extra Trees의 36개 설정, 합계 72개 설정을 비교했다. 피처 관측률 기준은 학습 부분에서 20%로 적용했으며 결측 대치·표준화도 학습 부분에서만 적합했다. 알고리즘 선택은 알려진 관련 La 합금 계열을 묶은 4-fold 개발 교차검증의 논문별 평균 MAE로 수행했다.

전체 풀 135개를 사용하는 별도 기준 실험에서는 두 입력 구성 모두 Ridge(alpha=100)가 선택되었다. 조성만 모델의 개발 OOF R²는 0.200, 기존 테스트 재평가 R²는 **0.097**, MAE는 0.256 log10 단위였다. 조성+조건 기준 모델의 재평가 R²는 −0.483이었다. 조건 피처가 물리적으로 불필요하다는 뜻은 아니며, 현재 결측·표본 구성과 제한된 모델 탐색에서 추가 피처가 개선으로 이어지지 않았다는 결과다.

이전 SVR의 −1.183보다 높은 점수가 나왔지만, 이미 결과를 확인한 동일 테스트를 다시 사용했다. **새로운 독립 검증에서 개선을 확인한 것으로 표현하지 않는다.**

## AL에서 정답을 가리는 방법

각 반복은 보고된 조성 서명 10개를 균등 무작위로 선택해 시작하고, 이후 5개씩 추가하여 52개까지 진행했다. 초기 선택은 각 seed 안에서 AL과 무작위 방법이 동일하다. seed 11, 22, 33, 44, 55의 5회 쌍 비교를 수행했다.

질의 하나는 해당 조성 서명의 모든 가용 조건 기록을 공개한다. 따라서 선택한 조성 수가 같아도 레코드 비용은 다를 수 있다. 조성 수와 실제 공개된 레코드 수를 모두 기록했으며, 서로 다른 레코드 비용을 무시하고 동일 실험비용에서의 효율 향상을 주장하지 않는다.

**각 라운드의 모델 설정은 그때까지 선택한 조성의 정답만으로 다시 선택했다.** Ridge 3개, SVR 2개, GPR 1개의 미리 정한 6개 설정을 최대 3-fold 관련 연구 그룹 교차검증으로 비교했다. 전체 풀 135개의 정답으로 선택한 기준 모델은 AL 학습기의 설정 선택에 사용하지 않았다. 적은 정답을 가진 단계에서 아직 선택하지 않은 정답을 간접적으로 사용하는 것을 막기 위해서다.

AL 획득 함수에는 미선택 자료의 **입력 피처만** 전달했다. GPR 표준편차 또는 선택 조성 묶음을 재표집한 8개 모델의 예측 불일치를 불확실성으로 사용하고, 현재 선택 자료와의 피처 거리로 다양성을 계산했다. 두 점수를 각각 정규화하여 0.5씩 합한 뒤 중복을 줄이는 배치를 순차 선택했다. 조성 묶음의 기록 수가 많다는 이유만으로 유리해지지 않도록 기록별 점수의 합 대신 평균을 사용했다. 이 불확실성은 교정된 통계적 신뢰구간이 아니다.

## 조성만 모델의 학습곡선

아래는 log10(i_corr) 기준 기존 테스트 재평가 R²의 5회 평균이다. 괄호는 seed 간 표준편차이며 신뢰구간이 아니다. 가장 높은 seed나 종료 시점을 결과로 선택하지 않았다.

| 선택한 조성 수 | 무작위 R² | AL R² | 무작위 공개 레코드 평균 | AL 공개 레코드 평균 |
| --- | ---: | ---: | ---: | ---: |
| 10 | −1.448 (1.561) | −1.448 (1.561) | 23.2 | 23.2 |
| 15 | −0.435 (1.574) | −0.145 (0.589) | 34.4 | 33.6 |
| 20 | −0.211 (0.708) | **0.164 (0.255)** | 43.2 | 46.0 |
| 25 | −0.670 (0.845) | −0.031 (0.167) | 54.6 | 55.2 |
| 30 | −0.403 (0.588) | −0.157 (0.428) | 69.2 | 66.2 |
| 35 | −0.211 (0.233) | −0.034 (0.116) | 83.8 | 81.2 |
| 40 | −0.451 (0.460) | −0.039 (0.044) | 99.0 | 94.0 |
| 45 | −0.264 (0.420) | −0.287 (0.496) | 116.6 | 113.8 |
| 50 | −0.154 (0.364) | −0.018 (0.384) | 126.4 | 125.2 |
| 52 | **0.097 (0.000)** | **0.097 (0.000)** | 135.0 | 135.0 |

20개 조성 예산에서는 AL의 R²가 5개 seed 중 4개에서 무작위보다 높았다. 40개 조성 예산에서도 4/5에서 높았지만, 45개 예산에서는 평균이 오히려 낮았다. 반복 수가 적고 테스트가 작아 우월성의 통계적 유의성을 주장하지 않았다. 조성만 모델에서 20개 시점이 가장 좋아 보이더라도 테스트 곡선을 보고 그 지점에서 멈추는 규칙을 만들면 테스트 기반 선택이 된다.

조성+조건 모델도 20개 예산에서 AL이 5/5 seed에서 더 높은 R²를 보였고, 25개 시점의 AL 평균은 0.253이었다. 그러나 50개에서는 AL 평균이 무작위보다 낮았다. 전체 곡선을 함께 제공하며, 일부 좋은 시점만 최종 성능으로 제시하지 않는다. AL의 6개 후보·최대 3-fold 선택 절차와 별도 전체 풀 기준 실험의 36개 후보·4-fold 절차는 다르므로, 조성+조건의 AL 마지막 점(0.084)은 별도 기준 모델 점수(−0.483)와 다를 수 있다.

## 무엇을 결론 내릴 수 있는가

**조성 중심 AL은 실행 가능하고, 현재 후향적 실험의 일부 예산에서는 유용한 조성을 먼저 확보했다. 그러나 AL은 정답 자체를 생성하거나, 모든 조성을 사용한 모델보다 반드시 높은 정확도를 보장하는 방법이 아니다.** 이 실험에서 52개를 모두 공개하면 두 질의 전략은 동일한 자료와 같은 모델 선택 절차에 도달하므로 결과도 같다.

현재는 정확도 향상보다 ‘어떤 조성을 먼저 측정하면 좋은가’를 평가한 단계다. 다음과 같이 실제 실험 설계에 연결하는 것이 사용자 목적에 더 가깝다.

1. 하나의 기지 합금 계열과 실제 사용할 시험 조건·열처리를 고정한다. 서로 다른 조건의 값을 같은 조성의 단일 정답으로 합치지 않는다.
2. 제조 가능한 조성 범위와 합계·원소 상한을 정하고, 실측 wt.%와 RE 함량이 확인된 초기 실험을 사용한다. 현재 문헌의 미보고 원소를 0으로 가정해 새 합금 조성을 제안하지 않는다.
3. **예측 정확도 향상**이 목적이면 불확실하고 학습 자료를 보완하는 조성을 선택한다. **낮은 i_corr 조성 탐색**이 목적이면 예측값과 불확실성을 함께 이용하는 별도 최적화 목적이 필요하다. 두 목적은 같은 것이 아니다.
4. 선택한 조성을 실제 제조·측정한 정답으로 업데이트한다. 문헌 값을 새 실험 결과처럼 재사용하지 않는다.
5. 획득·모델·종료 규칙은 개발 자료에서 정하고, 지금까지 사용하지 않은 논문 또는 별도 실험 배치에서 마지막으로 검증한다.

현재 결과로 조성 설계의 전역 최적값이나 R²≥0.8을 약속할 수 없다. 50편이라는 수보다 일관된 조건에서 독립적으로 측정한 조성–응답 쌍이 더 직접적인 다음 자원이다.
