# 모델 선택과 고정 테스트 결과 — 2026-10-19

**이번에 비교한 129개 설정 중 선택된 모델은 SVR이며, 고정 테스트 세트의 R²는 log10(i_corr) 기준 −1.183이다.** A/cm² 원래 스케일의 R²도 −0.854로, 현재 자료로 새 논문에 대한 충분한 예측력을 확보했다고 볼 수 없다. R²≥0.8은 달성하지 못했다.

## 데이터와 분할

44편·283개 통합본 전체를 학습에 넣지 않았다. 이전에 정의한 임시 모델 후보 24편·151개 레코드의 식별자를 유지하고, 현 통합본의 조성·조건·상 피처를 연결했다. 단위 미확정, 보류 및 그래프 추정치는 제외했다. 모두 pending이므로 결과는 검토 대기 자료의 탐색적 평가다.

| 용도 | 논문 수 | 레코드 수 |
| --- | ---: | ---: |
| 개발·학습 | 19 | 135 |
| 이번 고정 테스트 | 3 | 9 |
| 과거 테스트로 사용되어 이번 학습·테스트에서 제외 | 2 | 7 |

테스트 논문은 과거 저장된 모델링 결과의 입력에 없었던 추가 논문 세 편으로 고정했다. 앞선 기술적 해석에서 수치가 이미 공개되어 있었으므로, 완전히 눈가림된 외부 검증이라고 표현하지 않는다. 테스트 점수로 분할·모델·하이퍼파라미터를 바꾸지 않았다. 향후 이 세 편을 다시 이용해 설정을 고르면 더 이상 독립적인 테스트가 아니다.

| 테스트 논문 | 기록 | 논문별 MAE(log10) |
| --- | ---: | ---: |
| Q355NHq La/Ce, `10.11973/fsyfh-202403006` | 4 | 0.221 |
| 산업 생산 75Cr1 La/Ce, `10.13228/j.boyuan.issn0449-749x.20220781` | 2 | 1.010 |
| HRB400 RE, `10.20057/j.1003-8620.2024-00280` | 3 | 0.637 |

학습·테스트 DOI의 교집합은 없다. 개발 데이터 내부에서는 알려진 관련 La 합금 논문을 같은 그룹에 묶은 4-fold GroupKFold를 사용했다. 피처 결측률 기준, 결측값 대치, 표준화 및 범주 인코딩은 각 fold의 학습 부분에서만 적합했다. 원문 재사용이나 알려지지 않은 재료 계열의 완전한 독립성은 사람의 추가 검토가 필요하다.

## 무엇을 ‘최적’으로 선택했는가

Ridge, SVR, GPR, Random Forest, Extra Trees와 세 피처 구성(`corrosion`, `phase_corrosion`, `ml80`)을 비교했다. 각 모델의 미리 정한 그리드를 합쳐 129개 설정, 4-fold 기준 516회 CV 적합을 수행했다. 데이터가 많은 논문이 모델 선택을 지배하지 않도록 **OOF 절대오차를 논문별로 먼저 평균하고, 그 논문 평균들의 평균이 가장 작은 설정**을 선택했다. 동률이면 OOF RMSE를 사용하도록 정했다. 전 세계 모든 알고리즘에 대한 전역 최적 모델을 뜻하지 않는다.

| 모델별 선택 기준 최저 설정 | 피처 구성 | 개발 OOF R² | 논문별 평균 MAE(log10) |
| --- | --- | ---: | ---: |
| **SVR** | corrosion | **0.287** | **0.7936** |
| Ridge | corrosion | 0.269 | 0.7939 |
| GPR | corrosion | 0.279 | 0.8358 |
| Random Forest | corrosion | 0.173 | 0.9346 |
| Extra Trees | phase_corrosion | 0.028 | 1.0107 |

SVR과 Ridge의 선택 기준 차이는 약 0.00033 log10 단위로 매우 작다. SVR의 안정적인 우월성이 입증된 것은 아니다. 위 OOF 수치는 설정 선택에 사용한 개발 점수이므로 최종 일반화 성능으로 해석하지 않는다. 각 모델의 행은 그 모델 내 논문별 평균 MAE가 가장 낮은 설정이며, R²만 최대화한 설정을 뜻하지 않는다.

최종 선택은 RBF SVR, `C=10`, `gamma=0.01`, `epsilon=0.2`다. 학습 데이터에서 최종 선택된 입력은 P, S, Cr, Ni, Mo, Cu, N, RE 로그함량, 노출시간 로그값, 열처리온도, 역온도, 열처리시간 로그값, Cr+Mo, RE×Cr 및 RE×Mo 상호작용, 희토류 종류·전해질·기지·열처리 그룹이다. DOI·시료 ID·근거 문구는 예측 피처로 사용하지 않았다. 이 입력 선택은 보고 충실도에 의존하며 빠진 성분이 물리적으로 중요하지 않다는 뜻이 아니다.

## 테스트 결과

| 지표 | SVR | 학습 log 타깃 평균을 예측하는 기준모델 |
| --- | ---: | ---: |
| log10 타깃 R² | **−1.183** | −2.115 |
| MAE(log10 A/cm²) | 0.535 | 0.616 |
| RMSE(log10 A/cm²) | 0.625 | 0.747 |
| 논문별 평균 MAE(log10 A/cm²) | 0.623 | 0.626 |

원래 A/cm² 스케일에서 SVR의 R²는 **−0.854**, MAE는 2.71×10⁻⁵ A/cm², RMSE는 3.33×10⁻⁵ A/cm²다. 원래 스케일 예측은 선택된 log 모델을 10의 거듭제곱으로 역변환한 것이며, 원래 스케일의 평균 타깃을 별도로 최적화한 모델이 아니다.

R²는 `1 − SSE/SST`이다. 음수는 해당 테스트 세트에서 예측 오차 제곱합이 관측값의 테스트 평균 주변 변동보다 크다는 뜻이다. 선택한 모델이 학습 평균 기준모델보다 조금 낫다는 사실과 모순되지 않는다. 테스트 타깃 범위는 약 −5.325~−4.066 log10 A/cm²로 좁고 표본도 3편·9개여서 R²가 불안정하다. 그렇더라도 음수 점수를 숨기거나 유리한 분할로 교체하지 않는다.

MAE 0.535 log10은 `10^0.535 ≈ 3.43`의 오차 배수에 해당한다. 이는 절대 로그오차의 기하평균에 대응하는 설명이며 모든 예측이 3.43배 이내라는 보장이나 신뢰구간이 아니다. 각 논문의 기록이 2~4개뿐이므로 논문별 R²의 큰 음수값보다 MAE와 실제 예측값을 함께 확인하는 편이 적절하다.

## 데이터 해석과 연결

Q355NHq는 절대 전류의 규모가 비교적 가까웠으나, 모델은 실제 최소값이 나온 RE170을 정확히 재현하지 못했다. 실제 RE170은 2.25×10⁻⁵ A/cm², 예측은 약 5.39×10⁻⁵ A/cm²다. 따라서 모델이 이 계열의 최적 희토류 함량을 찾았다고 말할 수 없다.

산업 생산 75Cr1에서는 두 시료 모두 실제보다 낮게 예측해 가장 큰 오차가 생겼다. 무처리 C1은 실제 8.60×10⁻⁵ A/cm², 예측 약 6.41×10⁻⁶ A/cm²로 약 13.4배 낮다. HRB400에서는 반대로 세 시료 모두 실제보다 높게 예측했다. 이 결과는 시료별 RE 변화뿐 아니라 **새 연구의 절대 전류 수준을 맞추는 데 실패하는 논문별 편향**이 있음을 보여준다. 구체적인 원인이 누락된 환경·조성, 측정법 또는 출처 오류 중 무엇인지는 이번 평가만으로 구분할 수 없다.

현재 입력의 pH·환경·일부 기지조성 결측, 논문별 관측 수 불균형, 시험법 차이는 개선이 필요한 후보 요인이다. 통계적 원인 분석을 통해 확인한 결과는 아니다. 다음 단계에서는 조건이 일관되고 원문 검토가 끝난 서로 다른 연구를 늘리고, 관련 실험 계열을 묶은 평가를 유지해야 한다. 테스트를 본 뒤 개선안을 선택하면 이후 성능 주장은 새로운 논문 세트에서 검증해야 한다.
