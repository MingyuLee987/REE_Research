# 조성·제조 준비 방법을 이용한 i_corr 모델 비교

2026-10-19. 사용자 실험 정답은 추가하지 않았다. 문헌 입력을 보완하고 7개 알고리즘·4개 입력 구성·2개 가중 방식의 **208개 설정**을 비교했다. 개발 교차검증으로 선택한 모델은 **조성 전용 CatBoost**이며, 기존 테스트의 **log10(i_corr) R²는 0.322**였다. 이전 논문 균등 가중 Ridge의 0.145보다 높지만 새 독립 테스트 성능은 아니다.

제조·준비 조건까지 후보에 포함했으나, 현재 데이터에서는 추가 입력 모델이 선택되지 않았다. 따라서 ‘제조 방법 입력으로 R²가 높아졌다’고 결론 내리지 않는다.

## 데이터와 원문 보완

- 기존 적격 목록 24편·151개를 유지했다. 새 레코드·가상 정답·그래프 추정 정답은 추가하지 않았다.
- 개발 19편·135개, 기존 테스트 3편·9개를 유지하고 과거 테스트 2편·7개는 제외했다. 관련 La 논문 3편은 하나의 계열로 묶었다.
- 원문 24편의 준비 방법 후보 문장을 검토하고, 근거가 명확한 9편에서 73개 필드/레코드 수준 주석을 보완했다. 이 중 2편은 기존 테스트 논문으로, 준비 방법 입력만 보완했으며 학습에는 넣지 않았다.
- 기본 조성 외에 균질화 온도·시간, 압연 시작·종료 온도, 판재 두께, 코일링 온도, 최종 소둔, 냉각 방식, 표면 연마 조건을 입력 후보로 만들었다. 종료 온도의 범위는 최솟값·최댓값으로 보존했다.
- H13과 HSLA 논문은 가열/오스테나이트화와 후속 뜨임을 별도 필드로 분리했다. 담금질만 한 시료에 뜨임 조건을 배정하지 않았다.
- 금상 관찰용 연마 조건과 전기화학 전극의 준비 조건을 구분했다. 예를 들어 Q355NHq의 염수분무 시편 1000번 연마를 극화 전극 조건으로 쓰지 않고, 전기화학 절의 2000번을 사용했다.
- 미보고값은 결측으로 보존했다. 실온을 임의로 25°C로 변환하지 않았고, 재료명으로 제조 온도나 미보고 성분을 추정하지 않았다.
- 원본 `llm_pending_all.csv`는 변경하지 않았다. AI 원문 대조 보완이며 사람의 독립 검증은 아직 완료되지 않았다.

원문 위치·입력별 근거는 `03_분석결과와실험계획/90_이전분석기록/01_조성_제조방법_모델비교/preparation_overlay_evidence.json`, 모델용 사본은 `enriched_eligible.csv`에 저장했다. 근거 문구는 단위 표기를 정규화하거나 번역한 발췌이므로 원문의 정확한 직접 인용과 구분한다. 후보 문장을 모은 `preparation_source_snippets.json` 자체를 텍스트 피처로 학습시키지는 않았다.

기존 적격 목록에서 열처리 종류는 7편, 온도는 4편, 시간은 3편에만 입력되어 있었다. 원문 보완 후에도 대부분의 상세 공정값은 소수 연구에 집중된다. 같은 합금·다른 제조 조건을 독립 논문 여러 편에서 비교하는 데이터가 부족하다.

## 입력과 모델

| 입력 구성 | 포함 항목 |
| --- | --- |
| 조성 | 보고 원소 wt.%, log(1+RE ppm), RE 종류 |
| 조성+준비 | 조성, 열처리·압연·냉각·표면 준비 |
| 조성+준비+환경 | 위 입력, 용액 종류·농도, 온도, pH, 노출시간, 주사속도, OCP 대기시간, 기준전극, 사전 노출 조건 |
| 보고 조직 추가 | 위 입력, 저자가 보고한 기지·이차상 그룹. 조성에서 상을 예측해 채우지 않음 |

비교 알고리즘은 Ridge, SVR, Kernel Ridge, Gaussian Process Regression, Extra Trees, HistGradientBoosting, CatBoost다. 각 입력 구성에 26개 모델 설정과 무가중/연구 계열 균등 가중을 적용했다.

전처리·결측 대치·표준화·입력 선택은 각 학습 fold에서만 적합했다. 숫자 피처는 학습 자료의 독립 연구 계열 2개 이상에서 보고되고 변동이 있을 때 사용했다. 범주도 2개 계열 이상에서 지지되는 값을 유지하고, 나머지 보고값을 `other_reported`, 미보고값을 `not_reported`로 구분했다. 이는 출처를 간접 식별하는 효과를 줄이기 위한 처리지만 완전히 제거한다는 보장은 없다. DOI·시료 ID·출처 파일명은 예측 입력으로 사용하지 않았다.

전통 모델은 중앙값 대치·결측 지시자·표준화·원핫 인코딩을 사용했다. CatBoost는 숫자 결측을 그대로 받아들이고 범주 문자열을 사용했다. 범주 원핫 상한은 30으로 고정했다. [CatBoost 결측 처리 문서](https://catboost.ai/02_연구설명과논문작성/en/concepts/algorithm-missing-values-processing)를 따른다.

## 선택과 검증

목표는 `log10(icorr_A_cm2)`다. 4-fold 연구 계열 그룹 교차검증에서 **계열별 평균 제곱오차를 균등 평균한 RMSE**를 최소화했고 동률 시 전체 OOF RMSE를 사용했다. 큰 논문 한 편의 많은 레코드가 선택 지표를 독점하는 것을 줄였다. 테스트 점수로 설정·입력 구성을 선택하지 않았다.

선택 과정 자체를 점검하기 위해 외부 3-fold, 내부 3-fold의 **중첩 그룹 교차검증**도 수행했다. 외부 fold마다 208개 설정의 탐색을 처음부터 반복했고, 최종 선택 모델 하나만 재검증하는 방식으로 대체하지 않았다. 일반 교차검증의 최적 설정 점수는 선택 편향이 있을 수 있으므로 [scikit-learn 중첩 교차검증 설명](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)에 따라 두 수치를 구분한다.

선택 모델 설정:

- CatBoostRegressor 1.2.10.
- 조성 전용, 무가중.
- 깊이 3, 240회 부스팅, 학습률 0.04, L2 정규화 10, RMSE 손실, seed 42.
- early stopping으로 테스트 정답을 사용하지 않았다. 반복 횟수도 테스트로 조정하지 않았다.
- 사용한 숫자 입력은 C, Si, Mn, P, S, Cr, Ni, Mo, Cu, Al, N, Nb, Ti, V, log(1+RE ppm), 범주는 RE 종류다. W·Sb는 학습 자료의 보고 지지 기준을 만족하지 못했다.

## 결과

각 행은 해당 입력 구성 안에서 개발 교차검증으로 선택한 모델이다. 208개 모델을 모두 테스트해 가장 높은 테스트 점수를 고른 표가 아니다.

| 입력 구성 | 선택 모델 | 개발 OOF R² | 기존 테스트 R² |
| --- | --- | ---: | ---: |
| 조성 | CatBoost | **0.376** | **0.322** |
| 조성+준비 | Ridge, alpha=1000 | 0.171 | −0.450 |
| 조성+준비+환경 | Ridge, alpha=1000 | 0.160 | −0.270 |
| 보고 조직 추가 | Ridge, alpha=1000 | 0.167 | −0.221 |

모든 표의 R²는 log10 목표 기준이다. 선택 모델의 기존 테스트 로그 RMSE는 0.348, 로그 MAE는 0.292다. 모델 선택을 포함하는 **중첩 개발 OOF R²는 0.079**다. 최종 4-fold 탐색의 0.376과 같은 수치로 취급하지 않는다. 외부 fold마다 선택 모델도 달랐으므로 모델 선택의 안정성은 아직 낮다.

비교 기준인 이전 가중 Ridge는 테스트 로그 R² 0.145, MAE 0.216, RMSE 0.391이었다. 새 모델은 **R²·RMSE가 개선됐지만 MAE는 악화**했다. 몇몇 큰 오차를 줄였다고 모든 관측값의 전반적인 오차까지 줄어든 것은 아니다.

로그 예측을 `10**prediction`으로 변환했을 때 원래 A/cm² 단위의 테스트 R²는 **−0.615**다. 이는 로그 손실로 학습한 모델의 단순 역변환 결과이며, 원래 단위의 평균을 직접 최적화한 모델이나 로그정규 편향 보정 결과가 아니다. 따라서 ‘원래 단위에서도 예측력이 높다’고 주장하지 않는다.

테스트는 이미 여러 번 결과를 확인한 3편·9개 자료다. **0.322는 재사용 테스트의 탐색적 점수이며, 사용자 합금의 새로운 실험에서 검증한 성능이 아니다.** 실제 정답이나 분할을 변경하여 점수를 높이지 않았다.

## 제조 조건 추가가 개선으로 이어지지 않은 해석

현재 표본에서는 상세 제조 조건의 결측이 많고, 특정 조건이 합금 계열·논문과 함께 나타난다. 새 논문으로 넘어가면 같은 입력 관계가 유지되지 않을 수 있다. 135개 레코드도 독립 연구 계열로는 18개뿐이다. 복잡한 공정 입력이 추가되어도 독립적인 조합 수가 충분하지 않다.

이는 공정이 부식에 중요하지 않다는 물리적 결론이 아니다. 현재 자료와 제한된 탐색 범위에서 준비 조건 입력의 일반화 이점을 확인하지 못했다는 결과다. 가장 유망한 후속 문헌 작업은 ‘더 많은 필드’ 자체보다 **같은 기지 조성에서 서로 다른 압연·열처리·냉각 조건을 비교한 연구의 수치와 시험 조건을 함께 확보하는 것**이다.

CatBoost 내부 중요도 상위는 Mo, Ni, Cr, Mn, N이었다. 이는 이 혼합 문헌 모델의 분기 기여도이며 인과적 원소 효과나 Ce 최적 함량을 뜻하지 않는다. 보고 빈도·합금 계열과의 연관도 반영된다.

## 사용자 합금과 AL에 적용할 범위

이번 모델은 POSEIDON600의 1000°C 압연·900°C 15분 수냉 공정 효과나 Ce 300 ppm의 내식성 개선을 검증한 모델이 아니다. 기존 개발 자료에는 Cr<5%의 Ce 단독 첨가 사례가 없고, 사용자 합금 실측 정답은 여전히 없다. 따라서 사용자 조성에 대한 예측은 외삽이며, 문헌 테스트 점수 0.322를 사용자 합금의 기대 R²로 사용하지 않는다.

현재는 문헌 기반 기준 모델로 CatBoost를 저장하고, 기존 [Ce 실험 AL 계획](casting_ce_active_learning_20261019.md)은 별도로 유지한다. 새 실험이 들어오면 고정된 공정·부식 조건의 Ce 로컬 모델을 갱신한다. 문헌 모델 예측을 실험 정답으로 넣거나 AL이 이미 성능을 높였다고 집계하지 않는다.
