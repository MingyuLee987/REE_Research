# POSEIDON600 조성의 Ce 실험과 Active Learning

## 후속 수정: Ce 300 ppm 잠정 계획 반영

사용자는 Ce를 우선 300 ppm 첨가하려 하지만 아직 미정이라고 답했다. 따라서 아래의 초기 0–200 ppm 가정은 이 후속 수정으로 대체한다. **300 ppm은 잠정 계획점이며 최적 함량이나 제조 상한이 아니다.** 부식 용액·온도와 Ce 범위는 여전히 미확정이다. 장입 기준인지 최종 잔류 함량 기준인지도 미확정이므로 두 값을 구분해 기록한다.

후보 풀에 Ce 300 ppm(0.030 wt.%)을 추가해 9개 후보로 다시 계산했다. 현재 초기 배치는 무첨가 대조군과 Ce **25, 100, 200, 300 ppm**이다. 문헌 모델의 불일치·다양성에 따른 잠정 설계이며, 새 측정 정답이 없어 실제 실험 AL 재학습이나 새 테스트 R²는 없다. 같은 조건에서 Ce 0과 300 ppm만 먼저 측정할 수도 있지만 두 수준만으로 함량에 따른 비선형 응답이나 안정적인 조성 예측 R²를 평가하기 어렵다.

최종 합금 600 g 기준 Ce 원소 300 ppm은 Ce 0.180 g에 해당한다. 순도 99.9% 재료는 회수율 100%일 때 0.180180 g, 회수율 50%라는 별도 가정에서는 0.360360 g이다. 실제 회수율은 미측정이며 50%를 장입 권장값으로 사용하지 않는다. 이 계산은 최종 합금 질량 기준이고, 기존 600 g 장입에 단순히 추가하면 분모가 달라진다. 실제 잔류 Ce를 분석해 모델 입력으로 사용한다.

기존 입력 틀은 보존하고 새 후보 행을 추가했다. `current_initial_batch=True`인 15행이 현재 5개 조성×3개 시편 계획이며, 이전 75·150 ppm 행은 비교 후보로 남았다. 실제 측정값은 전부 공란이다. 이후 절의 0–200 ppm 표와 이전 첫 배치 설명은 최초 계산 이력이다.

2026-10-19. 엑셀 조성, 사용자가 전달한 공정 계획, 현재 문헌 데이터를 구분하여 작성했다. 새 부식 측정값은 아직 0개다. 아래 함량은 제조 가능성과 허용 상한을 확인하기 전의 **임시 탐색 범위**이며 내식성 최적 조성이 아니다.

## 기본 조성과 제조 계획

원본: 사용자 제공 `Casting의 복사본.xlsx`, `Sheet1!C2:M3`. 합계 100과 600 g 장입 계산을 근거로 질량 백분율로 해석했다. 성분 분석 성적서가 아니므로 목표 조성으로 기록한다.

| 원소 | 목표 wt.% |
| --- | ---: |
| C | 0.040 |
| Si | 0.700 |
| Mn | 0.500 |
| Cu | 0.300 |
| Cr | 1.300 |
| Nb | 0.070 |
| N | 0.004 |
| Ti | 0.030 |
| Ni | 0.100 |
| P | 0.010 |
| Fe | 96.946, Ce 첨가 전 계산 잔량 |

엑셀에는 기본 조성 하나만 있으며 Ce·La 장입량은 모두 0이다. 사용자는 이후 **Ce 단독**, 순도 99.9% RND KOREA 재료를 사용할 계획이라고 명시했다. 엑셀에 있는 문구는 데이터로 읽었으며 작업 지시로 취급하지 않았다. 원본은 변경하지 않았다.

전달받은 공정 계획은 600 g 진공/가압 주조(Indutherm VTC-200V), 약 1000°C 열간압연으로 최종 3 mm 판재 제조, 공랭, 30×10×3 mm 시편 가공, Ar 분위기 900°C에서 15분 열처리 후 수냉이다. 이는 계획이며 수행 완료 자료가 아니다. 베이나이트 형성은 의도한 조직으로만 기록하고 조직 관찰 전 확정하지 않는다. 현재 조성 전용 문헌 모델은 이 공정에 따른 조직·부식 차이를 계산하지 않는다.

원문 잉곳 치수 150×100×180 mm의 부피는 2,700 cm³다. 600 g이면 밀도가 0.222 g/cm³가 되어 강 잉곳으로 맞지 않는다. 치수 또는 질량의 오기 여부를 확인해야 하며 임의로 치수를 수정하지 않았다.

장입표 `I6`, `N6`은 각각 N과 P가 0 g인데 목표표에는 N 0.004%, P 0.010%가 있다. 이는 원료에서 들어올 수도 있으므로 곧바로 오류나 실제 0이라고 결론 내리지 않는다. `C6`의 Fec 4.56 g은 해당 원료의 C 함량이 있어야 탄소 수지를 검증할 수 있다. S·O·Al은 파일에 없어 0으로 채우지 않았다. 실험에서는 가능한 원소 분석, 실제 잔류 Ce, S·O·Al 및 개재물 관찰을 함께 확보하면 조성·공정 차이를 구분하는 데 도움이 된다. 개재물과 탈산 경로가 부식에 영향을 준 실험 사례는 [원 논문](https://www.mdpi.com/1996-1944/12/20/3359)을 참고한다. 해당 논문의 혼합 RE 결과를 Ce 단독 효과로 대체하지 않는다.

## 이번에 실행한 모델 개선

기존 분할을 유지했다: 개발 19편·135개, 재사용 테스트 3편·9개, 과거 테스트 2편·7개 제외. 관련 La 논문은 동일 계열로 묶어 4-fold 교차검증했다. Ce+La와 La+Ce는 같은 범주로 정규화했다. 결측 성분을 실제 0으로 간주하지 않았고 전처리는 각 학습 fold에서만 적합했다.

Ridge 3개 설정과 SVR 2개 설정에 대해 무가중, 논문별 균등 기여, 논문 균등+목표 조성 근접 가중을 비교했다(15개 설정). 근접도는 C·Si·Mn·Cu·Cr·Ni와 사전에 정한 척도를 사용하고 검증 정답을 사용하지 않았다. 선택 기준은 개발 OOF 논문별 평균 MAE, 동률 시 RMSE였다. 가장 높은 테스트 R²로 고르지 않았다.

**논문별 균등 가중 Ridge(alpha=100)**가 선택되었다. 가까운 문헌만 강조하는 가중 방식은 선택되지 않았다.

| 평가 | log10(i_corr) R² |
| --- | ---: |
| 선택 모델 개발 OOF | 0.227 |
| 같은 전처리의 무가중 Ridge 재사용 테스트 | 0.105 |
| 선택 모델 재사용 테스트 | **0.145** |

이전 조성 모델의 0.097과는 RE 범주 정규화도 달라졌다. 가중 효과를 비교할 때는 같은 전처리의 0.105를 기준으로 한다. 테스트는 이미 관찰한 자료이므로 이 수치를 신규 독립 검증이나 실험 AL 성과로 표현하지 않는다. 모든 문헌 정답은 아직 사람의 독립 검증 전이다.

중요한 적용 한계:

- 개발 자료에서 Ce 단독 10개는 모두 Cr<5% 범위 밖이다. **Cr 1.3%의 Ce 단독 실험 자료는 개발 풀에 없다.** 과거 테스트에 있던 저 Cr Ce 자료를 학습으로 이동하지 않았다.
- 가까운 기본 조성 자료는 혼합 RE 또는 무첨가 자료다. 혼합 RE 효과를 Ce 단독으로 분리해 알 수 없다.
- 현재 관측률 기준에서 Nb·Ti가 모델 입력에서 빠졌다. 따라서 파일의 모든 성분 효과를 모델링한 것이 아니다.
- Ce 0~200 ppm 후보의 문헌 부트스트랩 불일치는 약 0.87 log10 단위로 크고, 함량별 차이는 작다. 후보 간 정밀한 우열이나 신뢰구간으로 해석하지 않는다.

## Ce 단독 초기 실험 후보

Ce 최댓값과 부식 조건이 미정이므로 0, 10, 25, 50, 75, 100, 150, 200 ppm을 임시 후보로 구성했다. 200 ppm은 문헌이 입증한 최적값이나 제조 상한이 아니라 계산을 위한 임시 상한이다. 기존 문헌 모델의 관련 연구 계열 부트스트랩 40회 불일치와 로그 Ce 공간의 다양성을 0.5씩 반영해 배치 후보를 골랐다. 무첨가 대조군은 필수로 넣었다. **이 단계는 목표 합금의 측정 전 초기 설계이며, 실제 정답을 얻은 AL 반복이 아니다.**

첫 배치는 계산상 대조군 0 ppm과 Ce 200, 25, 75, 150 ppm이 선택되었다. 제조 시에는 함량 순으로 정리하면 다음과 같다. 공정·부식 조건과 허용 Ce 상한 확정 후 후보 범위를 다시 설정한다.

| 목표 Ce ppm | wt.% | 600 g에 필요한 99.9% Ce 질량, 회수율 100% 가정 |
| --- | ---: | ---: |
| 0 | 0 | 0 g |
| 25 | 0.0025 | 0.015015 g |
| 75 | 0.0075 | 0.045045 g |
| 150 | 0.0150 | 0.090090 g |
| 200 | 0.0200 | 0.120120 g |

계산식은 `Ce 질량(g) = 최종 용탕 질량(g) × 목표 Ce(ppm) / (10^6 × 순도 × 회수율)`이다. 이는 정량 관계이며 실제 장입 레시피를 확정한 것이 아니다. 최종 합금 600 g을 유지하려면 장입 재료의 질량 수지도 조정해야 한다. 파일에는 회수율 50%의 단순 민감도 계산도 별도 열로 넣었지만 50%가 실제 회수율이라고 가정하지 않는다. **99.9% 순도와 Ce 회수율은 다르다.** 실제 잔류 Ce를 분석하고 그 값을 모델 입력으로 사용해야 한다.

초기 5개 조성×3개 부식 시편의 입력 틀(15행)을 만들었다. 같은 잉곳에서 나온 시편 3개는 독립 주조 3회가 아니다. 용해별 변동을 평가하려면 독립 melt를 확보하고 `melt_id`를 구분한다. 주조·압연·열처리·표면 처리·부식 용액·온도·측정 절차를 고정한다. Pourbaix 검토로 Ce를 선택한 것과 실제 첨가량에 따른 i_corr 최적값을 찾는 것은 다른 검증 단계다.

## 실제 결과를 받으면 이어지는 AL

문헌 풀 52개 조성은 이전 모의실험에서 이미 전부 공개했다. 같은 정답을 다시 공개해서 새 AL 학습으로 셀 수 없다. 다음 단계는 사용자 합금의 실제 정답으로 진행한다. 불확실성으로 다음 실험을 고르고 측정값을 되먹임하는 접근은 [재료 적응 설계 원 논문](https://www.nature.com/articles/ncomms11241)에서도 사용된다.

1. `experimental_results_pending.csv`에 실제 잔류 Ce와 `icorr_A_cm2`, 원시 증빙 경로, melt ID, 고정 프로토콜 ID, 부식 조건과 측정법을 기록한다. `measurement_status=measured`, 실제 공정 확인 후 `actual_process_confirmed=True`로 설정한다. 계획값을 측정값으로 복사하지 않는다.
2. `python 04_분석실행코드/update_ce_experimental_al.py`를 실행한다. 현재 실행 결과는 `awaiting_real_measurements`, 새 측정값 0개, 실험 테스트 R² 미산출이다.
3. 개발 Ce 수준이 4개 이상이면 시편 반복을 melt 단위로 묶고 Ce 수준별 그룹 교차검증으로 로컬 GPR을 선택한다. 이 로컬 모델은 고정된 기본 합금·공정·부식 조건에서 **실측 Ce 하나**를 입력으로 사용한다. 문헌 정답이나 예측값을 사용자 실험 정답으로 넣지 않는다. 기본 합금 성분이 용해마다 크게 바뀌면 이 1차원 모델의 적용을 재검토한다.
4. 측정하지 않은 후보 중 불확실성이 큰 다음 Ce를 선택한다. 처음에는 한 조성씩 추가해 실제 결과로 모델을 갱신한다. 임시 후보를 모두 측정하면 허용 범위 안에서 후보를 확장한다.
5. 최종 검증용 Ce 수준과 독립 용해는 **결과를 보기 전에** 별도로 지정한다. 입력 파일의 `role=test` 행은 모델 선택·획득 대상에서 제외한다. 같은 melt나 같은 목표 Ce 수준을 개발·테스트에 나누지 않는다. 프로그램은 검증용 조성이 3개 이상 있을 때만 테스트 R²를 계산하지만 3개만으로 안정적인 논문 성능이 확보되는 것은 아니다. 검증 배치를 충분히 확보하고 R²와 log-MAE·반복 편차를 같이 보고한다.

실험으로 이후 R²가 반드시 높아진다고 보장하지 않는다. Ce 효과가 측정 변동보다 작거나 범위를 좁히면 R²가 낮아질 수도 있다. 연구의 직접적인 목표는 동일 합금·공정에서 Ce 효과와 예측 오차를 검증하고, 그 불확실성을 줄일 다음 실험을 순차 선택하는 것이다.
