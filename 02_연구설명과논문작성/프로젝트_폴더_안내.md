`01_논문원문과데이터/processed/pilot100/llm_pending_all.csv`는 중국어 논문을 포함한 **수집 원본**입니다. 현재 분석 파일과 혼동하지 마세요. 현재 제외본은 첫 번째 폴더의 `llm_pending_all_no_chinese.csv`입니다.

현재 전체 제외본은 **33편·228개 기록**, 모델 적격 자료는 **17편·119개**입니다. 기존 테스트 논문이 모두 제외되어 현재 고정 테스트 R²는 없습니다. 예전 R²=0.322를 현재 제외본 점수로 사용하지 않습니다. 자세한 내용은 [중국어 논문 제외 설명](no_chinese_20261019.md)을 보세요.

## 코드 실행

프로젝트 최상위 폴더에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe 04_분석실행코드/exclude_chinese_language.py
.\.venv\Scripts\python.exe 04_분석실행코드/update_ce_experimental_al.py
```

첫 명령은 현재 제외 기준으로 모델을 재평가합니다. 두 번째는 실제 Ce 실험값이 입력되었을 때 로컬 AL을 갱신합니다. 실험값이 없으면 결과를 만들지 않고 대기 상태를 기록합니다.

`.env`는 API 설정, `.venv`는 실행 환경, `.git`은 변경 이력입니다. 이 기술용 숨김 항목은 이름을 유지합니다. 파일을 삭제하지 않고 이동했으며, 경로 대응과 텍스트 경로 수정 내역은 `03_분석결과와실험계획/최상위폴더_이동기록.json`에 있습니다. 원문 PDF와 수치는 보존하고 저장된 파일 경로를 새 위치로 갱신했습니다.
