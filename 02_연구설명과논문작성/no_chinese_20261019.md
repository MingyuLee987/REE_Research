2026-10-19 사용자 요청에 따라 **본문이 중국어인 논문**을 분석 대상에서 제외했다. 저자 국적·소속이나 출판사 소재지를 기준으로 제외하지 않았으며 중국 소속 저자가 쓴 영문 논문은 유지했다. 사용자가 중국 소속 연구 전체 제외를 의도한 경우에는 별도 기준 변경이 필요하다.

원본과 이전 분석 결과는 수집·분석 이력으로 보존했다. 이번 분석은 아래 제외본과 전용 실행 코드를 사용한다. 기존 역사적 실행 스크립트의 원본 CSV 기본 경로를 일괄 변경한 것은 아니다.

## 모델 재평가

제외 후에도 기존과 같은 7개 알고리즘, 4개 입력 구성, 2개 가중 방식의 208개 설정을 비교했다. 개발 단계의 연구 계열별 RMSE를 기준으로 선택했다. 제조 준비 방법의 기존 보완값은 남은 논문에 대해서만 재사용했고 미보고값이나 정답을 생성하지 않았다.

- 선택 모델: **조성 전용 Ridge(alpha=100), 연구 계열 균등 가중**.
- 선택에 사용한 4-fold 개발 OOF log10(i_corr) R²: **0.309**.
- 전체 모델 선택을 외부 fold 안에서 다시 수행한 3×3 중첩 그룹 CV R²: **−4.358**.
- 현재 고정 테스트 R²: **미산출**.

중첩 검증 결과는 새로운 연구 계열에 대한 예측이 매우 불안정하다는 뜻이다. 단순 개발 최적값 0.309만 최종 성능으로 사용하지 않는다. 관련 La 자료의 비중이 큰 불균형한 소표본에서 계열을 통째로 제외하면 학습 분포가 크게 바뀐다. 이 결과만으로 언어에 따른 자료 품질 차이나 제외의 인과 효과를 판단하지 않는다.

기존 테스트였던 Q355NHq, HRB400, 산업 75Cr1 논문은 모두 이번 제외 목록에 포함됐다. **이전 테스트 R²=0.322는 제외본 모델의 점수가 아니다.** 점수가 잘 나오는 대체 테스트를 임의로 고르지 않았고 과거 테스트 정답을 학습에 옮기지 않았다. 다음 테스트는 별도 영문 문헌 또는 사용자 실험 배치를 결과 확인 전에 지정해야 한다. 현재 자료는 여전히 사람의 독립 검증 전이다.
