# 이전 분석 기록

지금의 중국어 논문 제외 기준을 적용하기 전 결과 또는 초기 단계 결과입니다. 연구가 어떤 순서로 진행됐는지 확인할 때 사용합니다.

| 폴더 | 진행 목적 |
| --- | --- |
| `01_조성_제조방법_모델비교` | 조성·열처리·표면 준비 조건을 추가해 모델 비교 |
| `02_조성별_AL_모의실험` | 기존 정답을 가리고 순차 공개해 AL과 무작위 선택 비교 |
| `03_폐기된_AL실험_참고용` | 설정 선택에 문제가 있어 대체된 초기 실행. 성능 주장에 사용하지 않음 |
| `04_이전_테스트평가` | 이전 고정 테스트에서 모델 평가 |
| `05_문헌데이터_해석` | 문헌 관측값의 분포와 동일 연구 내 비교 |
| `06_금속조직_변수분석` | 보고된 기지·이차상 정보를 입력으로 활용 |
| `07_입력변수_설계비교` | 어떤 조성·시험 조건 변수를 사용할지 비교 |
| `08_초기_개발검증` | 초기 개발 데이터 검증 |
| `09_초기_소규모_예비모델` | 작은 자료로 분석 코드와 모델을 시험 |

현재 자료는 상위의 `01_현재분석_중국어논문제외`에 있습니다. 이 폴더에 있는 테스트 점수는 현재 제외본 점수가 아닙니다.
